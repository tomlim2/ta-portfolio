## 프로젝트 설명과 LLM 협업 개발 사례 정리

프로젝트별 담당 범위와 실제 활용 단계를 명확히 하고, 이력서와 포트폴리오 설명을 맞췄습니다.

- Shotloom의 리타게터, 에디터 UX·편집 플로우, UX Writing과 개발 우선순위 기준을 정리했습니다. SceneGen은 여러 활용 예시 중 하나로 구분하고 흐름도를 해당 섹션으로 옮겼습니다.
- Claude·OpenAI 도구를 사용하는 4인 공동 개발의 가드레일·문서화와 이를 지원한 Knitten 개발 하네스를 소개했습니다. 이력서의 협업 항목과 다운로드 PDF에도 반영했습니다.
- Cinev Studio의 NPR 역 톤매핑 대응, 캐릭터 파츠 분리와 색상 변형, 웹 VRM의 Studio 변환·썸네일 반환, 클로즈업용 텍스처 기준을 보강했습니다. VRM 흐름도는 ImageGen 개념 설명도로 추가했습니다.
- 프로파일링의 UE 에디터 측정 조건과 제작팀 공유 과정, PMX의 사내 기술 검증 단계, Matcap의 실제 활용과 MMD Player의 개인 검증 용도를 명확히 했습니다.
- Live UE Scene Bridge의 상태 피드백과 프롬프트·호출 구조 개선을 설명하고, 포트폴리오 맵을 갱신했습니다.

한·영 페이지, 데스크톱·모바일 레이아웃과 A4 한 페이지 이력서 PDF를 확인했습니다. 공개 빌드는 HTML 10개와 로컬 참조 199개를 검증합니다.
