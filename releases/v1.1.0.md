## Shotloom 포트폴리오 사례 공개

- 홈페이지에 Shotloom 썸네일과 상세 사례 링크를 추가했습니다.
- 기본 3D 작업 플로우, 자사 모션·에셋 서비스 연동, 손쉬운 편집 경험이라는 세 가지 설계 목표를 정리했습니다.
- 리타게터의 공통 기준과 어댑터 구조, 뒤틀림 해결, 스트립 중심 타임라인, IK 코어와 후속 UI 개발의 협업 범위를 소개합니다.
- SceneGen 흐름도에 CINEV의 이미지 입력·최종 영상 생성과 Shotloom의 2–4단계 작업을 구분했습니다. 편집한 모션·카메라를 반영한 씬 동영상이 CINEV로 전달되는 흐름을 표시했습니다.
- 기존 프로젝트의 공통 스타일과 한·영 전환을 적용했습니다.

Shotloom 제품은 핵심 제작 흐름을 구현해 개발 서버에 배포한 단계였습니다. 이번 공개 대상은 해당 작업을 설명하는 포트폴리오 사례입니다.
