## 변경 내용

- TA 소개를 기술 탐색·검증과 실제 제작 도구·제품 구현 경험 중심으로 정리했습니다.
- 경력 기간과 담당 범위를 갱신하고, 읽기 쉬운 1페이지 이력서와 다운로드 PDF를 반영했습니다.
- NPR, 캐릭터 제작 도구, 프로파일링 사례에 기술 선택의 이유와 구현 결과를 보강했습니다.
- 수치의 측정 범위와 프로젝트 진행 단계를 명확히 하고, 근거가 부족한 성과 표현을 정리했습니다.
- 한글·영문 소개와 프로젝트 설명을 함께 갱신했습니다.

## 배포 방식

- 버전 태그를 푸시하면 공개 파일 검증, GitHub Pages 배포, 릴리즈 노트 생성이 순서대로 실행됩니다.
- 배포 파일 목록을 명시해 로컬 초안과 작업 노트가 사이트에 포함되지 않도록 했습니다.
