# 디자인 포트폴리오 통합 및 공통 UI 개선

## 추가

- TA 포트폴리오와 같은 스타일의 디자인 홈을 `/design/`에 추가했습니다. 기존 데모릴과 6개 프로젝트를 제공하고, 두 포트폴리오 사이를 푸터에서 이동할 수 있습니다.
- Office of Civic Innovation, Curiosity, Olivia, Personal Projects, Summer VR Project, Junkyard를 로컬 상세 페이지로 이식했습니다. 기존 `children/` 상세 주소는 새 페이지로 연결됩니다.
- Junkyard의 웹 인터랙션 데모 6개와 원본 미디어를 함께 옮겼습니다. 별도 호스팅된 Command G는 기존 주소로 연결합니다.

## 개선

- 모든 프로젝트 푸터를 메인과 같은 연락처·이력서·GitHub·LinkedIn·포트폴리오 전환·언어 선택 구성으로 통일했습니다. 상세에서도 이력서를 미리보기 모달로 열 수 있습니다.
- 이미지 미리보기는 화면의 80% 영역에 맞춰 열리며, 래스터 이미지는 원본 크기를 넘겨 확대하지 않습니다. SVG는 화면 맞춤과 150% 확대를 제공하고, 이미지에서 누른 위치를 기준으로 확대합니다.
- 미리보기 상단 높이를 41px로 줄이고 제목과 아이콘을 작게 조정했습니다.
- Personal Projects의 영상 17개를 음소거 자동·반복 재생하도록 변경하고 수동 재생 컨트롤을 유지했습니다.
- 페이지 템플릿과 스타일·컴포넌트 문서를 현재 구성에 맞췄습니다.

## 검증

- 배포 대상 파일의 로컬 링크·앵커·HTML 구조 검증을 수행했습니다.
- 데스크톱과 모바일에서 페이지 배치, 공통 푸터, 언어 전환, 이미지·이력서 미리보기와 영상 자동 재생을 확인했습니다.
- Vimeo 원본 링크를 함께 제공하며, 외부 임베드 재생은 브라우저와 서비스의 허용 설정에 영향을 받을 수 있습니다.
