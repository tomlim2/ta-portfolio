# 소개 페이지와 공용 팝오버

- TA·디자이너·프론트엔드 포트폴리오의 소개를 독립 페이지로 분리했습니다. 기존 홈의 `#about` 링크도 새 소개 페이지로 연결됩니다.
- 상단 내비게이션을 작업·소개 링크로 정리하고, 모바일에는 소개 링크를 표시합니다. 이름 로고는 각 포트폴리오 홈으로 이동하며, 한국어에서는 `임 연수`로 표시됩니다.
- 이름 로고와 메뉴를 64px 헤더의 세로 중앙에 맞추고, 소개 페이지의 큰 제목은 화면에서 제거했습니다.
- 공용 팝오버 컴포넌트를 추가해 언어 선택 메뉴의 열기·닫기, 포커스, 화면 경계 위치 보정을 통합했습니다.
- 이미지 미리보기의 로딩·실패 상태와 재시도를 보완하고, 미리보기 링크 및 이미지 요청 처리를 정리했습니다.
- 스타일 가이드, 컴포넌트 예시, 페이지 템플릿과 공개 파일 목록을 최신 구조에 맞췄습니다.
