# 공통 푸터와 언어 선택 메뉴 개선

- TA·디자이너 홈과 모든 프로젝트 상세의 푸터를 데스크톱·모바일에서 같은 구조로 통일했습니다.
- 이메일·이력서·포트폴리오 전환 링크와 저작권을 왼쪽에 정렬하고, 구분선과 실제 글자 기준의 위아래 여백을 조정했습니다.
- GitHub·LinkedIn 아이콘은 왼쪽, 언어 선택 버튼은 오른쪽에 배치하고 세로 중심을 맞췄습니다.
- 언어 선택을 지구본 아이콘과 현재 언어를 표시하는 버튼 및 위로 열리는 한국어·English 메뉴로 변경했습니다. 선택 저장, 키보드 이동, Esc 닫기와 포커스 복귀를 지원합니다.
- 디자이너 포트폴리오의 학력 표기를 “Degree with Distinction”으로 수정했습니다.
- 페이지 템플릿·스타일 가이드·컴포넌트 예시를 갱신하고, 공개 페이지 및 로컬 참조와 데스크톱·모바일 표시를 확인했습니다.
