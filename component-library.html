Buttons

Kind · Theme · Style을 독립적으로 조합합니다. 기본은 Text only + Outline, 테마는 시스템 설정을 따릅니다.

버튼의 종류, 테마와 스타일

Outline은 기본 버튼 배경색·텍스트색과 1px 테두리를 사용합니다. Filled는 같은 기본 배경색·텍스트색에서 테두리만 없앤 스타일입니다. Ghost는 투명 배경·투명 테두리에 같은 텍스트색을 사용하며, 호버 시 텍스트·아이콘 색상만 강조합니다. 테마를 전환해도 아래 Light / Dark 비교 영역은 각 테마를 유지합니다.

예시 버튼을 누르면 선택한 조합이 표시됩니다.

Hover: Outline·Filled는 배경, Ghost는 텍스트·아이콘 색상만 강조 · Pressed: 누르는 동안 더 진한 배경, Filled는 테두리 없음 · Focus: Tab 키로 확인하는 외곽선 · Disabled: 클릭·키보드 활성화 불가. 위 버튼은 동작 예시이며 파일을 다운로드하지 않습니다.

최소 높이 44px · 아이콘 전용 기본 44×44px / icon-group 32×44px · 글자 14px / 20px · 내부 간격 8px · 모서리 6px · 아이콘 20px / weight 300. 긴 텍스트는 줄바꿈하고 버튼 높이가 늘어납니다.

버튼 종류·테마·스타일 · HTML 코드

공통 css/style.css와 Google 아이콘 폰트를 로드하세요. download는 head의 icon_names에도 포함합니다. 실제 동작 핸들러와 텍스트를 연결하고 이동에는 a 요소를 사용하세요.

<!-- Default: text only + outline. Theme inherits from the page/system. -->
<button type="button" class="btn">Button</button>

<!-- Icon with text: keep translated text separate from the icon. -->
<button type="button" class="btn">
  <span class="material-symbols-outlined icon-sm" aria-hidden="true">download</span>
  <span data-ko="다운로드">Download</span>
</button>

<!-- Icon only: 44 × 44 target and a meaningful accessible name. -->
<button type="button" class="btn btn--icon" aria-label="Download">
  <span class="material-symbols-outlined icon-sm" aria-hidden="true">download</span>
</button>

<!-- Filled: default background and text, no visible border. Works with any kind. -->
<button type="button" class="btn btn--filled">Button</button>

<!-- Add btn--ghost to any kind. -->
<button type="button" class="btn btn--ghost">Button</button>

<!-- Explicit theme overrides: may wrap a group or sit on one button. -->
<div data-theme="dark">
  <button type="button" class="btn">Dark outline</button>
  <button type="button" class="btn btn--ghost">Dark ghost</button>
</div>
<button type="button" class="btn" data-theme="light">Light outline</button>

<!-- Use native disabled, not just reduced opacity or aria-disabled. -->
<button type="button" class="btn" disabled>Unavailable</button>

Usage & content rules

  • 짧은 이름·동작만: Resume, GitHub, Email처럼 목적이 분명한 한 줄 라벨을 씁니다. 이미 보이는 버튼 이름이 충분하면 중복 툴팁을 추가하지 않습니다.
  • 필수 설명은 화면에: 오류·비활성 이유·긴 설명은 본문이나 별도 도움말에 둡니다. 툴팁에 링크·버튼·이미지를 넣지 않습니다.
  • 접근 가능한 이름: 아이콘 전용 트리거는 기본 44×44px, icon-group 안에서는 32×44px 조작 영역과 라벨을 포함하는 aria-label을 제공합니다. 장식 아이콘은 aria-hidden으로 숨깁니다. data-tip이 이름을 대신하지 않습니다.
  • 키보드·터치: button 또는 a를 사용합니다. disabled 버튼이나 터치 화면에서는 툴팁 설명에 의존하지 않습니다. 탭은 원래 동작을 실행하며, 라벨을 보기 위한 첫 탭을 요구하지 않습니다.
  • 중복·번역: title을 함께 넣지 않습니다. data-tip과 aria-label은 자동 번역되지 않으므로 공통 이름을 쓰거나 두 속성을 함께 관리합니다.

현재 지원 범위: 아래쪽 고정 배치만 지원합니다. 줄바꿈·최대 너비·화면 경계 감지·자동 위치 전환·portal·Escape 닫기는 없습니다. overflow 조상이나 화면 끝에서 잘릴 수 있으므로 짧은 라벨과 여백을 확보합니다. 포인터를 툴팁 위로 옮겨도 표시를 유지하지 않으며, 독립된 role="tooltip" / aria-describedby 연결도 없습니다. 긴 설명이 필요하면 화면에 표시하거나 해당 동작을 갖춘 별도 컴포넌트를 사용합니다.

Media & Image Viewer

정적 결과·UI·노드 그래프는 원본 비율 이미지, 순서·타이밍·조작은 영상으로 보여줍니다. 비교 이미지는 같은 조건의 두 장을 모바일에서 위아래로 배치하고 각 캡션에 차이를 적습니다.

Detail image — original ratio / figure + caption / data-image-viewer

공통 미리보기 모달입니다. 왼쪽 이름 · 오른쪽 확대/화면 맞춤 · 맨 오른쪽 닫기. 래스터 이미지는 축소된 경우에만 원본 크기로 확대할 수 있습니다. 모달은 모든 화면에서 가로·세로 80% 크기로 중앙에 열립니다. 이미지를 누르면 확대하지 않은 미리보기만 엽니다. 래스터 이미지는 비율을 유지해 큰 이미지만 축소하고 작은 이미지는 원본 크기를 유지합니다. 확대해도 100%를 넘지 않으며, 원본이 모달에 들어가면 확대 기능을 숨깁니다. SVG는 원본 크기 제한 없이 비율을 유지해 영역에 맞추고, 별도 확대 시 그 표시 크기의 150%로 보여줍니다. 이미지를 누른 지점을 기준으로 확대하며 스크롤 가능한 범위 안에서 그 위치를 유지합니다. 툴바 버튼·키보드 조작은 중앙을 기준으로 확대합니다. 축소하거나 다시 열면 화면 맞춤으로 돌아갑니다. 창 크기가 바뀌면 선택한 모드를 유지하면서 확대·축소 가능 여부를 다시 판단합니다. 닫기·바깥 배경 클릭·Esc로 닫으면 원래 이미지로 포커스가 돌아옵니다. 미리보기에는 하단 캡션을 표시하지 않으며 본문의 캡션과 상단 제목은 유지합니다.

적용 후 완료 기준

  • 390px·768px·데스크톱에서 긴 한·영 제목, 표, 코드가 페이지 전체를 가로로 밀지 않는다.
  • 시스템 언어에 맞는 초기 선택과 한국어/English 전환·설정 저장 후 내용·폰트가 맞고, 카드·메뉴·이미지 확대가 동작한다.
  • Tab/Enter로 링크와 버튼을 조작하고, Escape로 이미지 뷰어를 닫으면 원래 링크로 돌아온다.
  • [REPLACE]·샘플 수치·샘플 미디어를 교체하고 측정 조건·담당 범위를 확인한다.
  • python3 scripts/build_site.py로 공개 페이지의 경로·앵커·h1 검증을 통과한다.

이 체크리스트는 적용 확인 항목입니다. 전체 접근성 적합성을 인증하는 것은 아닙니다. 현재 한계와 규칙도 함께 확인하세요.
